# Bounties — MyZubster Animal Registry

This repository follows the canonical [MyZubster Bounty System](https://github.com/MyZubster-Ecosystem/myzubster/blob/main/BOUNTIES.md).

## Eligible scope

Registry bounties may cover data validation, NFC payloads/scanning, verification providers, privacy-preserving mapping, tests, documentation and client integration.

## Evidence

A tag or submitted record is not automatically a verified identity. Acceptance criteria must define the registry/provider check and expected verification outcome.

## Animal welfare and privacy

Do not disturb animals or enter restricted/private areas for bounty evidence. Do not publish unnecessary owner information, private home locations or sensitive wildlife coordinates.

## Reward truth

Historical XMR amounts are not proof of payment. MYZ in the current core platform is an internal reward/accounting ledger; external settlement requires independent verification.

## Issues

Use this repository's GitHub issues and link the implementation PR/evidence to the selected bounty.
