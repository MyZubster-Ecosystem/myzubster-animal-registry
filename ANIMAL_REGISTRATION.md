# 📝 How to Register an Animal on MyZubster

## Step-by-Step Guide

### 1. Identify the Animal
- Take clear photos (at least 3)
- Note the species (scientific name preferred)
- Estimate age, size, and weight
- Note the location (GPS coordinates)

### 2. Choose Registration Fee

| Animal Type | Fee (XMR) |
|-------------|-----------|
| Small Pet (dog, cat) | 0.01 XMR |
| Large Pet (horse) | 0.05 XMR |
| Livestock (cow, pig) | 0.10 XMR |
| Wildlife (elephant, tiger) | 0.50 XMR |
| Endangered Species | 1.00 XMR |
| Aquatic / Insect | 0.005 XMR |

### 3. Submit Registration

**Option A: Via GitHub Issue**
1. Open a new issue using the `animal-registration.yml` template
2. Fill in all required fields
3. Submit the issue

**Option B: Via API**
1. Use the `/api/animals/register` endpoint
2. Provide all required data
3. Pay the registration fee in XMR

### 4. Verification
- Your animal will be in "pending" status
- Verifiers will check the information
- Once verified, the animal appears on the global map

### 5. Receive Rewards
- 0.001 XMR for registration
- 0.002 XMR for verification
- Additional rewards for updates
